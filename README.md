# GRUZO Telegram Bot (v4.1)

Telegram-бот для подбора грузчиков и разнорабочих в Москве и МО.

## Что реализовано

- Регистрация ролей: `👷 Грузчик` / `👨‍💼 Диспетчер`.
- Обязательное принятие правил сервиса при регистрации.
- Автоматический trial premium на 30 дней для нового пользователя.
- Главное меню (Reply Keyboard):
  - `📦 Заказы`
  - `👤 Профиль`
  - `📊 Мои заказы`
  - `💳 Подписка / Продлить подписку`
  - `ℹ️ Помощь` (+ `📜 Правила сервиса`)
- Создание заказа диспетчером в пошаговом режиме:
  - описание
  - адрес или геопозиция
  - дата/время
  - количество грузчиков
  - ставка/час
  - количество часов (минимум 4)
  - режимный объект (да/нет)
- Авторасчёт суммы заказа.
- Публикация заказа в группе с кнопкой `✅ Взять заказ`.
- Обновление сообщения в группе после того, как грузчик взял заказ.
- Приоритетные уведомления в ЛС грузчикам о новом заказе (premium выше в приоритете).
- Базовая монетизация:
  - free: до 15 заказов/мес для диспетчера
  - premium: без лимита (проверка активности подписки)
  - цена подписки 99 ₽/мес, VIP/Срочный 50 ₽ (заглушка под платежи)
- Профиль/статистика пользователя.
- Смена роли в профиле.
- Завершение заказа диспетчером + кнопка «✅ Рекомендую» и выставление оценки исполнителю.
- Явный юридический дисклеймер в правилах и профиле.

## Быстрый запуск (для новичка)

1. Установите Python 3.10+.
2. Создайте бота через `@BotFather`, получите токен.
3. Создайте файл `.env` рядом с `main.py`:

```env
BOT_TOKEN=ваш_токен_бота
GROUP_CHAT_ID=-1001234567890
YOOKASSA_SHOP_ID=demo_shop_id
YOOKASSA_SECRET_KEY=demo_secret_key
```

4. Установите зависимости:

```bash
pip install -r requirements.txt
```

5. Запустите бота:

```bash
python main.py
```

## Как подключить YooKassa (инструкция)

Сейчас в коде добавлены настройки и место для интеграции. Для полного подключения:

1. Зарегистрируйте магазин в YooKassa и получите `shop_id` и `secret_key`.
2. Добавьте эти значения в `.env`.
3. Реализуйте создание платежа (endpoint или команда в боте) через API YooKassa.
4. Поднимите webhook для подтверждения платежа.
5. По webhook при статусе `succeeded` вызывайте `db.set_premium(user_id, days=30)`.

## Настройка группы Telegram

1. Добавьте бота в группу/супергруппу.
2. Выдайте права администратора:
   - отправка сообщений
   - редактирование сообщений
   - закрепление сообщений (для VIP логики)
3. Получите `GROUP_CHAT_ID` (например через `@RawDataBot` или логирование апдейтов).
4. Укажите `GROUP_CHAT_ID` в `.env`.

## 24/7 запуск (systemd)

Пример unit-файла `/etc/systemd/system/gruzo-bot.service`:

```ini
[Unit]
Description=GRUZO Telegram Bot
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/opt/gruzo-bot
ExecStart=/usr/bin/python3 /opt/gruzo-bot/main.py
Restart=always
RestartSec=5
Environment="BOT_TOKEN=..."
Environment="GROUP_CHAT_ID=..."
Environment="YOOKASSA_SHOP_ID=..."
Environment="YOOKASSA_SECRET_KEY=..."

[Install]
WantedBy=multi-user.target
```

Далее:

```bash
sudo systemctl daemon-reload
sudo systemctl enable gruzo-bot
sudo systemctl start gruzo-bot
sudo systemctl status gruzo-bot
```
